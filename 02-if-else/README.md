# 02 — If-Else

Conditional statements in C: `if`, `else if`, `else`, and logical operators. These programs check conditions and make decisions based on the input.

## Programs

| # | File | Description |
|---|---|---|
| 01 | `01_even_odd.c` | Check if a number is even or odd |
| 02 | `02_largest_of_two.c` | Find the largest of two numbers |
| 03 | `03_largest_of_three.c` | Find the largest of three numbers |
| 04 | `04_positive_negative_zero.c` | Check if a number is positive, negative, or zero |
| 05 | `05_grade_calculator.c` | Calculate grade based on marks |
| 06 | `06_leap_year.c` | Check if a year is a leap year |
| 07 | `07_simple_calculator.c` | Basic calculator using if-else |
| 08 | `08_vowel_consonant.c` | Check if a character is a vowel or consonant |
| 09 | `09_character_case.c` | Check if a character is uppercase or lowercase |
| 10 | `10_divisible_by_5_and_11.c` | Check if a number is divisible by 5 and 11 |
| 11 | `11_triangle_validity.c` | Check if three sides can form a triangle |
| 12 | `12_profit_loss.c` | Calculate profit or loss based on cost and selling price |
| 13 | `13_electricity_bill.c` | Calculate electricity bill based on units (slabs) |
| 14 | `14_attendance_eligible.c` | Check exam eligibility based on attendance percentage |
| 15 | `15_roots_of_quadratic.c` | Find roots of a quadratic equation |
