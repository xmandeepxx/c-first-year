# C First Year

My C programming practice from 1st year of college (AI/DS). All programs written by me.

## Structure

- `01-basics/` — Variables, data types, input/output
- `02-if-else/` — Conditional statements
- `03-loops/` — for, while, do-while, nested loops
- `04-functions/` — Function declaration, parameters, return
- `05-array/` — 1D and 2D arrays, sorting, searching
- `06-string/` — String operations, palindrome, word count
- `07-struct/` — Structures, array of structs

## How to run

```bash
gcc filename.c -o filename
./filename
